# Kotlin Backend with Ktor -- Learning Path

  

A structured, hands-on guide to building backend services with Kotlin and Ktor. Each topic is a single file. Read in order. Write code at every step.

## Learning Objectives

By the end of this path you will be able to:

- Explain what Kotlin is, why it exists, and when to choose it over alternatives
- Write idiomatic Kotlin: null-safe, concise, expression-oriented
- Use coroutines and Flow for asynchronous, non-blocking backend work
- Build REST APIs with Ktor, from routing to authentication
- Persist data with Exposed (type-safe SQL)
- Serialize JSON with kotlinx.serialization (no reflection)
- Test, log, and deploy a Kotlin backend service

## How to Use This Path

1. Start at `00-foundations` if you are new to programming or Kotlin.
2. Skip to `01-first-code` if you know programming basics but not Kotlin.
3. Skip to `02-core-language` if you have written Kotlin but want depth on coroutines, Flow, and null safety.
4. Skip to `03-backend-fundamentals` if you know Kotlin and want to build APIs.
5. Everyone should read `04-production` before shipping.
6. `05-capstone` ties everything together.
